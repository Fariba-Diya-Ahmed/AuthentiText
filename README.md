# 📌 About the Project

**AuthentiText** is a Human vs AI text detection system developed using **Natural Language Processing, traditional Machine Learning, and transformer-based Deep Learning**.

The system analyzes a given text and predicts whether it was likely written by a **human** or generated by an **AI model**.

Three different classification approaches were explored:

* Logistic Regression
* Linear SVM
* DistilBERT

The baseline models use **TF-IDF** for feature extraction, while DistilBERT is fine-tuned for binary text classification.

Among the tested models, **DistilBERT achieved the best performance with 94.23% accuracy**.

# 🧠 Machine Learning Approach

## Baseline Models

Two traditional machine learning models were used as baseline approaches:

### 1. Logistic Regression

TF-IDF features are passed to Logistic Regression to classify the text into Human or AI.

```text
Text
 ↓
Preprocessing
 ↓
TF-IDF
 ↓
Logistic Regression
 ↓
Human / AI
```

### 2. Linear SVM

Linear Support Vector Machine was also trained using TF-IDF features.

```text
Text
 ↓
Preprocessing
 ↓
TF-IDF
 ↓
Linear SVM
 ↓
Human / AI
```

# 🤖 DistilBERT Model

For the advanced approach, **DistilBERT** was fine-tuned for binary text classification.

```text
Input Text
     ↓
DistilBERT Tokenizer
     ↓
DistilBERT
     ↓
Classification Layer
     ↓
Human / AI
```

The fine-tuned model predicts one of two classes:

* **Human**
* **AI**

The models were evaluated using **Accuracy** and **F1-Score**.

# 🔍 Error Analysis

A total of **22 misclassified samples** were observed during error analysis.

The errors show that distinguishing Human and AI text is not always straightforward. Some texts contain writing patterns that can be common to both human and AI-generated content.

This highlights the importance of having a diverse dataset with different writing styles and domains.

---

# ⚠️ Known Limitations

AuthentiText is **not a perfect AI detector**. Its predictions should be considered an AI-based estimation rather than absolute proof of authorship.

Some limitations include:

* Some human responses in the dataset may have been AI-assisted.
* AI-generated text that has been heavily **humanized or paraphrased** may sometimes be predicted as Human.
* Human writing styles can vary significantly.
* The dataset is relatively small compared to large-scale language datasets.
* Performance may decrease on text from domains that are very different from the training data.
* The model cannot determine with certainty who actually wrote a piece of text.

## 🔍 Humanization Loophole

One important limitation observed during testing is that AI-generated text can sometimes be modified to make it appear more human-like.

For example:

```text
AI-generated Text
       ↓
Humanization / Paraphrasing
       ↓
More Human-like Text
       ↓
Possible "Human" Prediction
```

This is a known challenge in AI-generated text detection and is an important area for future improvement.

# 🔮 Future Work

Several improvements can be explored in future versions of AuthentiText.

### 1. Humanized AI Detection

Generate human-like AI text using different paraphrasing or humanization techniques and **keep these samples labeled as AI**.

```text
AI-generated Text
       ↓
Humanization / Paraphrasing
       ↓
Human-like AI Text
       ↓
Label: AI
       ↓
Add to Training Data
```

This could help the model learn patterns from AI-generated text that has been modified to appear more human.

### 2. Dataset Expansion

* Collect more naturally written human responses
* Add more AI-generated samples
* Include more writing domains
* Increase the diversity of writing styles

### 3. Model Improvements

* Experiment with larger transformer models
* Compare additional NLP architectures
* Improve classification performance
* Explore ensemble approaches

### 4. Multilingual Support

Add support for **Bangla and other languages** to make the system more useful for local users.

### 5. Better Deployment

Deploy a more permanent and scalable version of the application with improved performance and availability.
